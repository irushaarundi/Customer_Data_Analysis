# Customer Churn & Retention Analytics

This project analyses telecom customer records to identify the factors that drive churn and the customer segments most at risk. It includes an exploratory data analysis and data-cleansing pipeline built in Python (pandas) that handles missing values, standardises fields and prepares the data for analysis. The original PySpark/Databricks code was migrated to pandas. The findings are presented in a Power BI dashboard showing churn drivers and segments, so business stakeholders can act on retention.

## Key Highlights

- Built an exploratory analysis and data-cleansing pipeline over customer records.
- Migrated PySpark/Databricks code to pandas.
- Delivered a Power BI dashboard presenting churn drivers and segments for business stakeholders.

## Tech Stack

Python, pandas, PySpark, Databricks, SQL, Power BI

cx_chrun_data.csv, site_location.csv
